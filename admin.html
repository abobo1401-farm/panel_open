4×4 パネル画像公開システム

読み込み中…
GitHub Pagesだけで使う場合：この管理画面はOBSの「カスタムブラウザドック」に登録して使うのがおすすめです。OBS表示と同じ保存領域を使えるため、画像・文字設定がそのまま反映されます。

基本設定

表面画像

1枚の画像を4×4パネルとして自動表示します。表面にはパネルの境目があります。

裏面画像

完成画像は1枚のまま背面に表示します。開いたパネル同士の境目は出ません。

①〜⑯へ個別画像を設定します。透過PNGにも対応します。

表面の文字

初期値はすべて「？？？」。入力すると自動保存され、OBS側へ反映されます。

効果音

音量

全パネル共通の短い「シュッ＋ポン」系SEです。16枚目も同じ音です。
